# DeepSeek V4.1 Flash — Crossplane V8 / Dyno Cell

90° 크로스플레인 V8 엔진을 산업용 다이나모 테스트 스탠드 위에 절차적 지오메트리로 구현한
실시간 Three.js/WebGL 시뮬레이터입니다.

![preview](preview.png)

## 실행

`index.html`을 Chrome, Edge, Safari 또는 Firefox에서 열면 됩니다.
로컬 파일(`file://`)로 바로 실행되며, 빌드나 웹 서버, 네트워크 연결이 필요 없습니다.

- Three.js r160과 폰트가 HTML 안에 인라인되어 있습니다.
- 텍스처, 형상, 데칼, 계기판까지 전부 실행 시점에 절차적으로 생성됩니다.
- WebGL2 지원 브라우저를 권장합니다. (데스크톱 1600×1000 기준 확인)

## 구현 내용

- **엔진 구조** — 90° V8, 2뱅크 × 4기통, 4개의 크랭크 스로우(45°/135°/225°/315°),
  크로스플레인 크랭크, 5개 메인 베어링, 16밸브 DOHC.
- **기구학** — 슬라이더-크랭크 식 `s = R·cosδ + √(L² − R²·sin²δ)`로 8개 피스톤을 구동.
  커넥팅 로드는 크랭크핀과 피스톤 핀 사이에 매 프레임 재배치됩니다.
- **4스트로크** — 720° 사이클을 기준으로 흡기/압축/폭발/배기를 계산하고,
  캠샤프트는 크랭크의 정확히 1/2 속도로 회전합니다. 밸브 리프트, 스프링 압축,
  버킷, 로브 위상이 모두 같은 크랭크 각도에서 동기화됩니다.
- **점화 순서** — 1–8–4–3–6–5–7–2, 90° 등간격. 실린더별 점화 플래시와
  배기 맥동, HUD 점화 LED가 연동됩니다.
- **PBR** — 캐스트 아이언, 단조 알루미늄, 단조 스틸, 크롬, 브러시드 머시닝,
  구리 가스켓, 배기 스테인리스 히트 틴트, 오렌지 파우더 코트, 고무, 세라믹을
  서로 다른 roughness/metalness/bump로 구성했습니다. PMREM 스튜디오 환경 반사를 사용합니다.
- **테스트 셀** — 배기가스 플로어 덕트, AC 다이나모, 벨하우징/커플링 가드,
  콘크리트 바닥, 안전 표시, 산업용 조명, 벽면 사인, 콘솔, 스택 라이트, 공구/드럼.
- **성능** — 1,200개 이상의 지오메트리, MSAA 4× + UnrealBloom + ACES 톤매핑.
  헤드리스 Chrome(1600×1000, DPR 1)에서 약 50 fps 수준으로 확인했습니다.

## 컨트롤

| 컨트롤 | 동작 |
|---|---|
| **START / STOP** | 점화 시동 및 정지. 정지 시 관성으로 감속합니다. RPM 0에서 START를 누르면 900 rpm으로 시동합니다. |
| **RPM CONTROL** | 0–4,000 rpm 슬라이더. 주행 중 목표 회전수를 바꾸면 실제 회전수가 부드럽게 추종합니다. |
| **SLOW MOTION** | 시간 배속 0.08×. 밸브 이벤트와 캠 로브를 눈으로 확인할 수 있습니다. |
| **ORBIT** | 좌클릭 드래그 회전, 우클릭(또는 Shift+드래그) 팬, 휠 스무스 줌. |
| **WALK** | 클릭으로 마우스 캡처 후 WASD 이동, Shift 달리기, ESC 해제. 엔진/스탠드를 통과하지 않도록 충돌 처리됩니다. |
| **RESET CAMERA** | 기본 히어로 시점으로 부드럽게 복귀합니다. |
| **CUTAWAY** | ON: 하우징을 X-RAY로 열어 내부를 노출. OFF: 완전한 주물 외관. (기본 ON) |
| **EXPLODED VIEW / ASSEMBLE** | 밸브 커버, 캠/밸브트레인, 헤드, 인테이크, 배기, 오일팬, 프런트 드라이브를 순차 분해/재조립. 분해 시 카메라가 자동으로 프레이밍됩니다. |
| **PART INSPECTION** | 파트에 마우스를 올리면 하이라이트/툴팁, 클릭하면 소재·기능·스펙 카드. **FOCUS ON PART**로 해당 파트에 카메라 포커스. |
| **RESET CAMERA** | 선택/툴팁을 정리하고 기본 시점으로 복귀합니다. |

### 키보드

`V` Orbit/Walk 전환 · `R` 카메라 리셋 · `C` Cutaway · `E` Exploded · `A` Assemble(Orbit 모드) · `Space` Start/Stop · `W A S D` Walk 이동 · `Shift` 달리기 · `Esc` 마우스 캡처 해제.

## 참고

- 기본 상태는 **CUTAWAY ON**입니다. 시작부터 피스톤, 로드, 크랭크, 캠샤프트,
  밸브 스프링이 보이도록 한 기술 시연 상태이며, CUTAWAY를 누르면 완전한 외관으로 돌아갑니다.
- 밸브는 실린더당 1개 흡기 + 1개 배기(총 16개)로 모델링되어 있습니다. UI/스펙에 표기된
  16밸브 DOHC와 일치합니다.
- 사운드는 의도적으로 넣지 않았습니다(브라우저 자동재생 정책과 벤치 환경을 고려).
