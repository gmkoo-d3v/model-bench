# GLM-5.3-Flash 산출물 — V8 엔진 시뮬레이터

## 실행

`v8-engine.html`을 더블클릭해 브라우저(Chrome/Edge/Safari 최신)로 열면 됩니다.
로컬 파일로 바로 실행 가능하며, Three.js r160은 CDN(jsdelivr)에서 로드됩니다.
오프라인으로 실행할 경우 CDN 로드 실패 — 인터넷 연결 필요.

## 구성

- 90° V8, 8기통 × 2뱅크, 크로스플레인 크랭크(0°/90°/270°/180°)
- 피스톤·커넥팅 로드·크랭크·캠샤프트(4축, ½속도)·밸브(2밸브/실린더, 버킷 리프터, 밸브 스프링) 실시간 연동
- 정확한 슬라이더-크랭크 기하: `s = R·cosδ + √(L² − R²·sin²δ)`
- 720° 사이클 완전 사행정 시퀀스, 발진 순서 1-8-7-3-6-5-4-2 (90° 간격 even-fire)
- 절차적 지오메트리만 사용 (다운로드 모델 없음): PBR 메탈 + RoomEnvironment 반사

## 컨트롤

| 컨트롤 | 동작 |
|---|---|
| START / STOP | 엔진 시동·정지 (RPM 관성 감속/가속, 절차적 엔진음) |
| RPM 슬라이더 | 0–4,000 RPM |
| SLOW MOTION | 시간 배속 ×0.08 (밸브 타이밍 관찰) |
| WALK (WASD) | 1인칭 걷기 모드 — 클릭으로 마우스 캡처, WASD+마우스, ESC 해제, V 토글, Space/C 상하 |
| ORBIT | 드래그 회전 + 휠 스무스 줌 |
| CUTAWAY | 블록/헤드/덮개 반투명 + 클리핑 절단면 (전통적 컷어웨이 뷰) |
| EXPLODED VIEW | 파트가 조립 순서대로 분해 (피스톤↔로드는 한 세트) |
| ASSEMBLE | 분해 상태를 되감아 재조립 |
| PART INSPECTION | 호버/클릭으로 파트 강조 + 정보 패널 (부품명·설명·재질), 파트 라벨 토글 |
| RESET CAMERA | 기본 시점으로 부드러운 복귀 트윈 |

## 하단·HUD

- 실린더별 점화 LED (폭발 순간 점등), 캔버스 타코미터, 테스트 스탠드 계기판에 RPM 디지털 표시
- 배기 매니폴드가 발진 펄스에 맞춰 붉게 발광
