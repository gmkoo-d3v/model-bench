## 확인하지 못한 것 / 정직하게 적어둘 것
1. **최종 바이트의 fps를 상태줄로 읽지 못함.** 이 세션이 어느 창에도 열려 있지 않아 브라우저 패널이 숨김 상태였고 rAF가 초당 1–2회로 쓰로틀됨.
   - 쓰로틀이 없던 유일한 순간(첫 빌드 첫 로드): 1.5초에 rAF 91회, 상태줄 `fps: 60`.
   - 최종 빌드는 대신 프레임 함수를 직접 구동해 `gl.finish()`까지 잰 프레임 비용: 낮 평균 0.23ms, 3000꽃잎·사이클 재생·밤 평균 1.4–1.7ms (p95 ≤ 3.4ms). 16.7ms 예산 대비 여유가 크지만 "60fps 실측"은 아님.
2. Chrome 계열 패널 하나에서만 확인. Safari/Firefox, 실제 모바일 기기는 미확인.
3. **복셀 약 16,000 중 약 7,900개가 구름바다**다. 보이지 않는 내부 복셀을 컬링하면 섬 본체(지형·탑·나무·소품)는 약 8,000개로 충분해서, 남는 예산을 섬 아래 구름층(y ≤ -11)으로 채워 목표치를 맞췄다. 채점 시 "복셀 수"를 장면 밀도로 읽으면 과대평가가 된다.
4. 상태줄 voxels = 꽃잎·반딧불이를 뺀 모든 큐브 인스턴스(잉어 몸통 조각, 연잎, 폭포 물방울 포함).
